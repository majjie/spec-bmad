# Lumen — Product Requirements Document

Lumen is a sibling initiative: a focused token-diff viewer that Harbor may embed later.

## Functional requirements

- **FR-1** Diff two token JSON snapshots side by side.
- **FR-2** Highlight only semantic tokens that changed.

### UJ-1 — Comparing brand packs

A designer picks “before” and “after” snapshots and scans highlighted rows.
